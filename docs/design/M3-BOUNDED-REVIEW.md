# M3 独立审阅设计评审

FR-010、DEV-011、TST-010、AC-010。此稿与隔离工作树中的实现供维护者评审。

## 授权与预算

工作台用户在活动 Run 中填写一个问题和明确选择的材料。主 Agent 无法通过工作台工具派发审阅。原生审阅会话从空会话起步，按独立预设运行，模型请求的工具表为空，工具执行另有 Host 拒绝。问题与材料合计最多 24 KiB，输出上限 1024 Token，运行最长 120 秒，深度 1。每次 Run 最多派发两次，同时只保留一项待核对审阅。保留 Harness 的提供方、模型和费率配置。

## 持久化与重启

派发前在任务记录中原子写入审阅 ID、预留子会话 ID、Run、请求人和请求回执。请求回执保存输入摘要。选中的材料随本次用户操作交给原生子会话。任务数据库存储问题及审阅摘要。相同请求 ID 重放读取已有状态，首次发送失败或结果未知时，用户通过“核对审阅”走只读查询。

核对同时检查 Run 阶段游标后的父会话目录事件和子会话原生头，包括预留 ID、父会话、工作目录、创建时间及审阅预设。证据不足时保留未完成标记。完成信号及正文取自已验证子会话的第一轮。仅将其归属该 Run 并记录输出截止游标，后续独立使用同一个原生会话产生的用量不计入审阅。

用户可显式将已完成审阅的摘要发送给该 Run 的主 Agent。工作台按当前用户发送摘要，正文附审阅 ID 和核查提示。审阅摘要作为建议供主 Agent 查验，接受交付继续使用现有的原生证据和用户确认。待核对审阅需要先处理才能结束 Run。

## 兼容与回退

公共契约在 v1 中新增四个 owner 操作。旧客户端可继续调用现有操作。任务存储的既有记录缺少审阅数组时按空数组读取。回退到不识别审阅记录的旧版本前，按部署流程备份状态并使用回退前的兼容数据。使用本地模拟模型验收派发、跨重启去重、已创建但未入账的恢复、子会话用量与显式回送。
