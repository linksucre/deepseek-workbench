# M2 工作台资料与阶段交接

DEV-010、FR-009、TST-011、AC-009。此稿供工作台接口评审。

## 读取与权限

沿用 owner 登录后的本机命令入口与同源校验。`task.context.index` 和 `task.context.load` 定义于 [v2 契约索引](../../contracts/v2/operations.json)。目录只返回该任务已登记且获准的资料引用、登记日期、来源类别和过期状态，以及上次阶段交接。资料正文在用户点选后读取。打开资料面板或读取资料不唤醒 Agent。联调版调用者可按 [部署说明](../DEPLOYMENT.md#从联调预览升级到-api-v2) 迁移命令地址。

文件预览由原生文件服务和任务工作区边界约束，读取限 64 KiB UTF-8，超限或无法核验时显示不可预览。已提交产物引用显示提交时的版本。对已登记的原生消息引用，目录按任务绑定的根会话检查范围，仅显示引用元数据。点选后核对事件是否存在及其类型，只返回该根会话内的用户或助手文本。工具结果、展示事件及无法核验的消息引用返回 `NOT_FOUND`，页面显示不可预览。链接仅展示 HTTP(S) 地址，由用户选择打开。载入正文前后核对任务修订和资料权限。

## 工作台入口

资料使用与现有验收证据相同的折叠结构。展开后，左对齐的资料列表显示位置与新鲜度，点选条目后在下方预览，长路径及正文使用换行。阶段交接显示阶段、已选执行方式、最近提交和验收决定。复制交接由用户主动操作。草稿及就绪编辑表单可记录工作区文件与网址，保留已有资料的原始路径、观测日期和原生会话引用。已存的文件名两端空格和无法在单行编辑器表示的路径同样保留。新录入的 HTTP(S) 地址使用宿主和表单共用的校验。文件预览保留 UTF-8 文件开头的 BOM 和正文换行。

## 兼容与验收

单独的目录和预览操作维持任务详情读取成本，旧存储无需迁移。备选方案是把资料正文内嵌到任务详情，打开任何任务都会触发文件读取，且会扩大上下文。回退时停用新增的只读命令和页面入口，已有来源仍保留在任务记录。

验收应覆盖浏览器录入来源和按需加载、无 Cookie 与跨源拒绝、未登记来源拒绝、越界和过期标记、重启后预览、纯文本呈现、提交时哈希及退回原因复读。真实 Host 测试使用本地模拟模型。
