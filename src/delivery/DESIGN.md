# 交付与证据

归属 FR-005。消费当前 Run 可访问的原生 present 事件与固定检查结果，按会话、序列和产物位置去重。提交前确认授权和可访问性，记录哈希或提交 ID，以及受验收条件约束的证据。

接受前重读版本。被替换、消失、越界或无法完成核验时交回明确结果，保留旧记录供比较。模型描述种类固定为 model-claim，检查退出码和用户确认分别由可信来源注入。

待评审方案由宿主从当前 Run 的原生展示事件解析产物、选择最新一次展示或指定文件，并在提交时生成版本和证据。输入与失败场景见 [M1 评审稿](../../docs/design/M1-RECOVERY-AND-SUBMISSION.md)。

[submission.mjs](submission.mjs) 从宿主提供的同一会话日志中按阶段游标选择最近展示，或按路径选择各文件最后一次展示。返回的交付引用由会话 ID、事件序号和文件位置组成。测试结果使用宿主已匹配验收条件的退出码和事件位置生成，模型描述不可进入这个入口。

[local-files.mjs](local-files.mjs) 是本地文件实现。调用方必须提供已验证的工作区、会话目录和逐路径授权函数。文件读取拒绝 symlink、越界及超限文件，同一文件句柄计算 SHA-256 并检查身份和版本是否改变。接收前重新计算版本。运行时可信的事件片段、检查映射及用户身份在宿主接入时提供，远程文件读取使用不同适配器。

[host-delivery.mjs](host-delivery.mjs) 从工作台已绑定的根会话读取原生观察视图。每次读取校验任务的工作区权限、注册表中的会话成员关系、根会话及实际目录。授权器由 Host 注入。阶段游标由业务服务提供，旧事件和未来事件不可被选择。当前实现针对本地文件系统。

真实 Host 验证命令为 `node tests/integration/host-delivery-smoke.mjs /path/to/built-deepseek-harness`。模拟模型触发两个原生 present 事件，重启后对冷会话选择产物并核验权限和阶段范围。再次重启前替换文件，使用此前保存的交付版本重新核验。测试使用固定授权和绑定夹具，生产身份接入及验收流程见 DEV-012。
