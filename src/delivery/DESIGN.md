# 交付与证据

归属 FR-005。消费当前 Run 可访问的原生 present 事件与固定检查结果，按会话、序列和产物位置去重。提交前确认授权和可访问性，记录哈希或提交 ID，以及受验收条件约束的证据。

接受前重读版本。被替换、消失、越界或无法完成核验时交回明确结果，保留旧记录供比较。模型描述种类固定为 model-claim，检查退出码和用户确认分别由可信来源注入。

待评审方案由宿主从当前 Run 的原生展示事件解析产物、选择最新一次展示或指定文件，并在提交时生成版本和证据。输入与失败场景见 [M1 评审稿](../../docs/design/M1-RECOVERY-AND-SUBMISSION.md)。
