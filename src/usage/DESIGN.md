# 用量与费用

归属 FR-008、NFR-006。消费原生 token-meter 投影与可证的结算事件，按稳定请求身份去重。多个作用域合并前验证归属，未绑定的会话列为覆盖缺口。费率依据提供方、模型与时间生效，未匹配费率时金额为空。

显示报告字段、估算币种和覆盖说明。缺报按未知计数；局部已知保留局部值。统计与任务更新需要能在禁用模型调用时重算。软预算仅作显示和提醒。

## 固定 Host 的数据源验证

运行 `node tests/integration/usage-host-smoke.mjs /path/to/built/deepseek-harness`。测试使用本地模拟响应覆盖正常用量、计数省略、显式零和带用量的提供方拒绝。前后两次 Host 进程读取相同的会话投影和原生历史，重启后的读操作未发起模型请求。提供方和模型可从 `request/context` 读取，正常结算来自 `assistant/message`，拒绝场景的已报告用量保存在 `assistant/attempt` 的最后一个 `usage` 流记录中。省略的缓存字段在结算中仍为空，显式报零则保留 `0`。`tokenUsage` 投影会把两种情况都聚合为零。固定版本的 DeepSeek Messages 适配器也会把缺失的输入和输出计数填为零，两种情况在该适配器的原生结算记录中无法区分。验证使用 Node `22.22.0`。 [测试入口](../../tests/integration/usage-host-smoke.mjs)

TST-006 实现应按会话和请求归集原生结算，使用投影对账。只有原生字段可证明已有报告时显示实报零。适配器丢失字段是否存在的信息时，标记覆盖缺口。取消结算、`llm/retry-started` 的重试边界以及子会话继承历史的去重仍需验证。原生模式下可能出现不在任务会话结算中的辅助模型调用，应独立对账。任务归属、费用估算和完整 TST-006 验收等待 DEV-006 的生产接入。

## 归集与估算实现

[`summarizeTaskUsage`](task-usage.mjs) 读取已核验的任务会话快照、Run 起始游标和原生继承前缀长度。同一会话的重复序列只处理一次，冲突或有缺口的历史会被排除并记覆盖缺口。继承前缀和 Run 启动前的调用不计入任务，同一步的 `llm/retry-started` 划定新的尝试。同一次尝试的更新保留最后一份可得结算，失败样本按原生日志保留。未报告字段返回 `null`，有部分样本时只汇总可得字段并标记 `partial`。标准 `deepseek-official` 路由的输入／输出零可能来自默认值；自定义路由的适配语义由宿主注入。

[`estimateCost`](usage-cost.mjs) 以每次尝试的时间查询已生效费率，使用整数和十进制字符串计算每百万 token 价格。用量缺报、缺少匹配费率或涉及不同币种时，金额为空。单一币种内使用多个费率日期时，`rateDate` 表示实际使用的最晚费率日期。试验使用固定合成费率，工作台生产费率加载和 `task.usage` 的入口接线仍待验证。

## 已授权的宿主读取

[`createHostTaskUsage`](host-usage.mjs) 接受已认证用户，并由调用方用 `loadTask` 和 `canReadSession` 分别执行任务授权与会话授权。根会话必须在工作区成员列表中，且其原生目录和根会话类型一致。子会话必须同时列在 Run 绑定中，出现在父会话的有效范围内，且原生头部的直接父 ID、创建时间和目录与父记录相符。外部执行、未绑定目录和不可读的会话计入覆盖缺口。读取前后重新检查授权，返回前复核任务 revision。较早的 Run 缺少可信起始游标时，省略其历史并标记缺口。当前契约只有 `endedAt`，已结束 Run 按首条达到结束时间的原生事件截断，避免纳入关闭后的使用量。

用量冒烟在重启后的真实 Host 内通过 `sessionQuery` 和 `workspaceRegistry` 读任务根会话，并用已知输入输出和失败用量对账。此试验使用受控的任务绑定及授权。子会话的目录和派生检查、访问撤销、缺失起点与结束时间过滤由单元测试验证。生产授权装配和真实子会话的完整 TST-006 仍需联调。 [宿主试验](../../tests/integration/usage-host-smoke.mjs)
